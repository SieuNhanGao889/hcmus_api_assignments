## Quy tắc ghi bug sau này

Một behavior chỉ được ghi là bug khi có đủ:

- Test case liên quan.
- Spec/requirement reference.
- Request và preconditions.
- Expected result dựa trên spec.
- Actual result từ lần chạy thật.
- Screenshot hoặc Newman/Postman evidence.
- Phân tích loại trừ lỗi setup/test implementation.
- GitHub Issue link thật nếu đã tạo issue.
